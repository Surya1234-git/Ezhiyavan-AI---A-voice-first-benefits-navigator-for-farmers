# Rule audit (2026-11-21)

Every draft scheme was compared with official or primary sources found by search. **This is research, not verification:** no scheme is verified, and exact pages and sections still need a human reviewer (`docs/VERIFY_PM_KISAN.md`).

| Scheme | Finding | Action taken |
|---|---|---|
| KCC | **Error.** Required owning land. RBI KCC Directions (19 Jun 2026) also cover tenant farmers, oral lessees, sharecroppers and allied-activity farmers. | Rule changed to "owns land OR leases land OR allied activity"; two questions added; tests added |
| PM-JAY | **Out of date.** Everyone aged 70+ has been covered since Oct 2024 regardless of income. | 70+ branch and question added; "answer no if unsure" wording removed; tests added |
| PM-KISAN | Rules match the official FAQ (read in full): own-name land only, tenants **not** eligible, the exclusion list, bank account compulsory. **Correction:** an earlier note about an NRI exclusion is **not supported** by the FAQ. **Not encoded:** land cut-off date 1 Feb 2019 (with succession exception). The Operational Guidelines PDF could not be fetched. | Evidence filled from the FAQ by question number; still a draft; reviewers must confirm |
| PMFBY | No land requirement, tenants and sharecroppers are covered, so the rules are fine. | Notes added; nothing changed |
| TN old-age pension | Age 60+ matches the state policy note. A farmers' pension scheme (Uzhavar Padhukappu Thittam) is **missing** from the app. | Notes added; scheme not added without a reviewed rule |
| TN widow pension | Sources disagree on a minimum age (30 vs 40). | Not encoded; reviewer must read the government order |
| TN disability | Official page says "unemployed"; secondary sources disagree on 40% vs 80%. | Not encoded; reviewer must read the government order |

Still unchecked: the exact criteria for the PM-JAY beneficiary list, and how a Tamil Nadu farmer enrols for the 70+ cover in practice.
